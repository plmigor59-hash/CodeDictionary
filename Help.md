 ### 1️⃣ Установка и запуск

   Шаг | Действие
  -----|--------------------------------------------------------------------------------------------------------------
   1   | Скачайте репозиторий (или склонируйте) в любую папку, например  D:\Dictionary .
   2   | Откройте решение  CodeDictionary.sln  в Visual Studio 2022 или новее (требуется .NET 10.0).
   3   | Скомпилируйте проект (Build → Build Solution).
   4   | После успешной сборки запустите полученный файл CodeDictionary.exe из каталога  bin\Debug\net10.0-windows .
       | Можно просто двойным щелчком по  CodeDictionary.exe .
   5   | При первом запуске приложение создаст локальное хранилище (JSON‑файл) в каталоге %APPDATA%\CodeDictionary
       | (по умолчанию).

  ### 3️⃣ Рабочий процесс

  #### 3.1 Создание новой записи

  1. Нажмите «+» в тулбаре или выберите Файл → Новый сниппет.
  2. Заполните поля:
      • Заголовок – короткое название.
      • Категория – выбирается из древовидного списка (можно создать новую через контекстное меню «Add Category»).
      • Описание – вводится в HTML‑редакторе (доступные инструменты: B, I, U, H1‑H3, List, Link, Image, Color).
      • Код – пишите в большом окне редактора; автодополнение сразу работает.
      • Теги – через запятую (для быстрого фильтра).
  3. Нажмите «Сохранить» (Ctrl + S). Запись появляется в дереве слева.
  #### 3.2 Редактирование существующей записи

  1. Выберите запись в дереве.
  2. Нажмите «Редактировать» (кнопка с карандашом) или двойным щелчком по записи.
  3. Внесите изменения в любые поля. При необходимости включите/выключите AutoFix (кнопка в тулбаре) – это переключает
  между чистым текстом и режимом IntelliSense.
  4. Сохраните (Ctrl + S).

  #### 3.3 Поиск и навигация
  • Быстрый поиск – поле в правом верхнем углу. Вводите любой текст, и список сниппетов фильтруется по заголовку, коду,
  тегам и описанию.
  • Продвинутый поиск – открывается через Ctrl + F; поддерживает регулярные выражения.
  #### 3.4 Работа с Python
  • При вводе кода Python активируется автодополнение (ключевые слова, встроенные функции, модули).
  • Форматирование ( Ctrl + Shift + F ) автоматически поправит отступы и расставит двоеточия.

  #### 3.5 Работа с BSL (1C)
  • При вводе кода BSL включается OneScript.Language‑парсер:
      • Автодополнение ключевых слов, глобальных процедур/функций и методов типов.
      • Signature Help – подсказка сигнатуры при вводе  ( .
  • Для запуска скрипта: нажмите ▶ Запустить в тулбаре. Вывод появится в нижней панели, её высоту можно менять
  ползунком.

  #### 3.6 Настройки интерфейса

   Параметр                                              | Как изменить
  -------------------------------------------------------|------------------------------------------------------------
   Тема                                                  | Меню Вид → Тема → Светлая / Тёмная.
   Шрифт редактора                                       | Настройки → Шрифт – выбирайте размер и семейство.
   Автосохранение                                        | Включить в Настройки → Автосохранение (каждые X сек).
   Путь к базе данных                                    | Настройки → Путь к файлу – укажите каталог для JSON‑файла.

  ### 4️⃣ Экспорт / импорт

  • Экспорт: Файл → Экспортировать → сохраняете весь набор сниппетов в JSON‑файл.
  • Импорт: Файл → Импортировать → выбираете JSON‑файл; существующие записи с тем же заголовком будут заменены
  (появится диалог подтверждения).

  ### 5️⃣ Часто задаваемые вопросы (FAQ)

   Вопрос                                     | Ответ
  --------------------------------------------|-----------------------------------------------------------------------
   Где хранится моя база данных?              | По умолчанию в  %APPDATA%\CodeDictionary\data.json . Путь можно
                                              | изменить в настройках.
   Как добавить новую категорию?              | Щелкните правой кнопкой мыши по корневой папке в дереве → Add
                                              | Category. Введите имя и нажмите Enter.
   Почему автодополнение не работает?         | Убедитесь, что файл открытый в режиме Python или BSL (выбор языка
                                              | слева от редактора).
   Можно ли настроить горячие клавиши?        | Да – в Настройки → Горячие клавиши задайте свои комбинации.
   Как включить/выключить автоформатирование? | Кнопка AutoFix в тулбаре отвечает за переключение между «чистым»
                                              | режимом и режимом с подсветкой/IntelliSense.
