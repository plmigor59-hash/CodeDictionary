# Справочник кода C#

WPF приложение для удобного хранения и организации примеров кода, методов и сниппетов на C#.

## Возможности

- **Добавление записей** - создание новых записей с названием, описанием, кодом и тегами
- **Категоризация** - организация записей по категориям
- **Поиск** - быстрый поиск по названию, описанию, коду и тегам
- **Фильтрация** - фильтрация записей по категориям
- **Редактирование** - изменение существующих записей
- **Удаление** - удаление ненужных записей
- **Автосохранение** - данные сохраняются в JSON файл

## Структура записи

Каждая запись содержит:
- Название
- Категория
- Описание
- Код (с моноширинным шрифтом для удобства чтения)
- Теги (для дополнительной классификации)
- Дата создания и изменения

## Хранение данных

Данные сохраняются в файл `data.json` в папке:
```
%APPDATA%\CodeDictionary\data.json
```

## Использование

1. Запустите приложение
2. Нажмите "Добавить запись" для создания новой записи
3. Заполните поля: название, категорию, описание, код и теги
4. Нажмите "Сохранить"
5. Используйте поиск и фильтры для быстрого доступа к нужным записям

## Технологии

- .NET 10.0
- WPF (Windows Presentation Foundation)
- JSON для хранения данных
