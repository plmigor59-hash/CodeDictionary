# CodeDictionary

CodeDictionary — это мощное WPF-приложение для систематизированного хранения, организации и редактирования фрагментов кода (сниппетов). Оно разработано для программистов, которые хотят создать личную базу знаний с удобным интерфейсом.

## Основные возможности

*   **Управление сниппетами**: Создание, редактирование и организация записей.
*   **Продвинутый редактор кода**:
    *   Встроенная подсветка синтаксиса для множества языков (AvalonEdit).
    *   Поддержка тем оформления (Темная/Светлая).
    *   Вкладочный интерфейс для одновременной работы с несколькими файлами/записями.
    *   Возможность сворачивания блоков кода.
    *   Настройка шрифтов и переноса строк.
*   **BSL (1C:Enterprise) интеллектуальное редактирование**:
    *   Контекстная автодополнение (CompletionWindow) для ключевых слов, глобальных процедур/функций, типов и их методов.
    *   Member-Access completion по точке (`Объект.Метод`) с выводом методов и свойств соответствующего типа.
    *   Signature Help — всплывающая подсказка с сигнатурой функции/процедуры при вводе `(`.
    *   Полноценный синтаксический и лексический анализ на базе парсера **OneScript.Language**.
    *   Система типов BSL (Булево, Число, Строка, Структура, Массив, Соответствие, ТаблицаЗначений и др.) с методами для каждого типа.
    *   Глобальный контекст 1С — более 130 встроенных функций и процедур (Сообщить, Вопрос, Найти, Лев и т.д.).
    *   Кнопка отключения автодополнения (AutoFix) в панели инструментов — мгновенно переключает между текстовым режимом и режимом с подсветкой/IntelliSense.
*   **Гибкое форматирование**: Поддержка стилизации отдельных сегментов кода (цвет фона, шрифта, жирный/курсивный текст).
*   **Организация**: Древовидная структура категорий с поддержкой Drag-and-Drop.
*   **Поиск и навигация**: Быстрый полнотекстовый поиск по коду, заголовкам, описаниям и тегам.
*   **Персонализация**: Сохранение состояния окна и настроек интерфейса.

## Структура записи

Каждая запись включает:
*   **Заголовок**: Краткое описание сути сниппета.
*   **Категория**: Путь в иерархическом дереве.
*   **Описание**: HTML-описание для документации.
*   **Код**: Непосредственно код с подсветкой синтаксиса.
*   **Теги**: Метки для быстрой фильтрации.

## Технологии

*   **.NET 10.0**
*   **WPF** (Windows Presentation Foundation)
*   **AvalonEdit** (редактор кода)
*   **OneScript.Language** (парсер и синтаксический анализ BSL)
*   **Material.Icons.WPF** (иконки в интерфейсе)
*   **System.Text.Json** (сериализация данных)

## Начало работы

Просто запустите исполняемый файл приложения. Данные сохраняются в локальном хранилище, указанном в настройках приложения.
